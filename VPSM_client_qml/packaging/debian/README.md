# Debian package

The minimum supported baseline is Debian 12 Bookworm with Qt 6.4. Build the
package inside the oldest Debian release that must run it. Native compilation
is intentional: `dpkg-shlibdeps` records ABI package names and minimum symbol
versions from that Debian installation.

## Build dependencies

```bash
sudo apt update
sudo apt install --no-install-recommends \
  build-essential cmake ninja-build pkg-config dpkg-dev \
  qt6-base-dev qt6-declarative-dev libssl-dev \
  qml6-module-qtquick qml6-module-qtquick-window \
  iproute2 sudo
```

`doas` may be installed instead of `sudo`. Debian packaging prefers `sudo` on
a clean system. At runtime the client tries `doas` first, but if it is present
and not configured it automatically retries through `sudo`.

## Build

From the repository root:

```bash
./VPSM_client_qml/packaging/debian/build_deb.sh
```

Optional build variables:

```bash
VERSION=0.2.0 \
BUILD_DIR=/tmp/vpsm-deb-build \
OUTPUT_DIR="$PWD/out" \
./VPSM_client_qml/packaging/debian/build_deb.sh
```

The output is written to `VPSM_client_qml/dist/` by default:

```text
vpsm-client_0.1.0_amd64.deb
vpsm-client_0.1.0_amd64.deb.sha256
```

Install it with:

```bash
sudo apt install ./VPSM_client_qml/dist/vpsm-client_0.1.0_amd64.deb
```

## Package contents

- `/usr/bin/vpsm_client` — unprivileged Qt Quick GUI;
- `/usr/bin/vpsm_tunnel_headless` — CLI/headless client;
- `/usr/libexec/vpsm/vpsm_net_helper` — minimal privileged TUN helper;
- `/usr/share/applications/vpsm-client.desktop` — launcher with a terminal for
  the `doas`/`sudo` password prompt.

The exact ELF dependencies are generated by `dpkg-shlibdeps`. Runtime-loaded
requirements are declared explicitly: `sudo | doas`, `iproute2`, and the Qt
Quick QML modules.

The package does not install a passwordless privilege rule. Administrators may
allow only `/usr/libexec/vpsm/vpsm_net_helper` after auditing it; do not grant
privileges to the entire GUI executable.
